# Project Data

- `reference/` contains durable source tables used by shared package code.
- `market_listings/` contains exchange and ETF directory snapshots generated by `Research/Single Asset/Pricing/ETF Testing.ipynb`.
- `company_data/` at the project root remains the local ticker-level cache managed by the existing data clients.

Notebooks should resolve the project root first and build paths beneath this directory instead of writing CSV files beside notebooks or at the repository root.
